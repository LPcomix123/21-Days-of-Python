# 21-Days-of-Python

A little Python project I’m making for the Stardance Sticky Streaks challenge! I’ll spend the first 3 days on the foundation, then add a new feature every 3 days. By the end, it’ll have 6 fun features all in one place.

#How to install!

Note in the terminal spaces before or after the commands do not matter
1. Go to the Github Repository,
2. Click the green "Code" button
3. If your not already on the local menu; click local at the top
4. Click "Download ZIP"
5. In your terminal enter this exact command: cd 21-Days-of-Python
6. Now enter this command to run the program: python main.py
7. You have successfully completed this setup guide to test out the program, Good job! :)
